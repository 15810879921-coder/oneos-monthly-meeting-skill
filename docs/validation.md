# v1.0.0 验证记录

验证日期：2026-10-24。样例全部为虚构文字与合成截图，不含真实月报或业务数据。

- 11 项针对性检查通过：未审核正文／口播／截图拒绝生成、截图指纹绑定、异常坐标拒绝、RGB 像素永久遮盖与去元数据、长文和指标溢出拒绝、品牌素材指纹检查、缺字库拒绝、用户明确时限超限不交付、字段不静默丢弃。
- 完整生成 7 页样例，覆盖封面、目录、章节、截图内容、手机截图指标、计划和结束页。产出静态 PPT、有声 PPT、逐页图片与声音、完整声音、脚本和视频。
- 在线语音使用固定音色与参数；样例时长 17.60 秒，用于验证管线，不作为正式月报长度范例。
- 视频回读为 3840×2160、30 fps、H.264、AAC 48 kHz 双声道，无字幕流；视频、整段音频与逐页时序一致。
- PPT 解包回读内嵌音频、自动播放起始条件和逐页切换时序；交付目录及 PPT 媒体均不包含原始截图。
- 人工视觉检查全部页型，桌面／手机截图在对应页右侧，正文、Logo、页脚未被遮盖；遮盖区域已变为实心像素。
- macOS WPS 实际打开有声 PPT，并观察到播放期间从封面自动切换到后续页。

边界：本次没有验证接手者机器的 PowerPoint／WPS 版本和扬声器输出；不据此宣称所有播放器均兼容。首次正式使用须在实际演示机试播，并逐页试听业务口播。工具链的结构和像素检查不替代 AI 对真实截图的语义审查。

复现方法（交给 AI 执行）：安装根目录 requirements.txt 后运行 `python -m unittest discover -s tests -v`；`python tests/run_acceptance.py --online --output .local/new-acceptance` 会将虚构口播提交给配音服务并生成完整样例。省略 `--online` 仅生成带草稿标识的无配音检查稿。输出目录必须为空。
